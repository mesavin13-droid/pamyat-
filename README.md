# ПАМЯТЬ

Сервис ухода за местами захоронения в Новосибирске.

## Что уже в репозитории

- Mobile-first интерфейс клиента.
- Выбор категории по давности последнего ухода:
  - Ухаживаем регулярно — 2 990 ₽
  - 3–6 месяцев назад — 4 290 ₽
  - 6–12 месяцев назад — 5 990 ₽
  - Больше года назад — 7 900 ₽
  - Не знаю — 4 290 ₽
- Фото клиента не обязательны.
- Отдельные режимы Клиент / Исполнитель / Администратор.
- Чек-лист исполнителя: Фото ДО → работа → Фото ПОСЛЕ → проверка.
- Supabase schema: Auth, профили, места памяти, заказы, фото, оплаты, RLS, Storage.
- Защита суммы заказа серверным триггером по `care_pricing`.
- После завершения заказа место памяти получает дату последнего ухода и рекомендуемую следующую дату.

## Запуск

Node.js 20+.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Без Supabase проект работает в DEMO MODE.

## Supabase

В SQL Editor выполнить:

```
supabase/schema.sql
```

Затем задать:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

В браузере используется только publishable key. Секретные ключи платёжного провайдера должны храниться только в Edge Functions / Secrets.

## Важный момент по цене

Клиент выбирает только категорию ухода. Сумма проверяется в базе по таблице `care_pricing`.

При спорной ситуации фактический объём должен быть согласован с клиентом до начала дополнительных работ.
